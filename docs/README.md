# 🐜 Mayi Agent Plus 架构与实战手册

欢迎查阅 **Mayi Agent Plus** 官方技术文档。本项目是从零重构的新一代桌面通用智能体客户端，旨在用最干净的工程分层解决复杂长周期任务（如数百份工程招投标资料解析与方案编纂、跨表数据分析、自动化代码工程等）。

---

## 为什么重构？三大核心准则

1. **重活离线确定化，在线推理轻量化**  
   彻底将耗时的 PDF 逐页提取、RapidOCR 识别、Office 容器解析移出大模型单步工具调用的热路径。先批量转为带 `<!-- page: N -->` 页码锚点的结构化 Markdown 缓存（`.workspace/parsed/`）与全局 `INDEX.md` / `toc.md` 地图，让模型的所有搜索和阅读回归毫秒级纯文本操作。
2. **薄内核 + 文件即状态（Workspace as Memory） + 厚技能（Skills）**  
   前后端协议、会话存储和 AgentScope 运行时**不包含一行垂直行业代码**。所有中间状态都是工作区里透明可读的普通文件（`01-requirements.md`、`02-plan.md`、`drafts/01-xxx.md`），天然支持断点恢复与人工实时微调。
3. **生成与验证物理隔离 + 自适应人机门禁**  
   复杂任务在完成“约束提炼 + 目录/计划拆解”后触发门禁确认，对齐后再并发产出；验收环节坚持“确定性脚本硬检 + 独立干净上下文 Reviewer 审查”双保险。
